# How to run this thing
Copy entire repository, make sure you have [node](https://nodejs.org/en) and then use in terminal:
- `npm install`
- `npm run dev`

Add .env in base folder and put here:
- `EMAIL_USER= your email`
- `EMAIL_PASS= your email password`
