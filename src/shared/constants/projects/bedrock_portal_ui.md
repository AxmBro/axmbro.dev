Bedrock Portal UI is a commissioned set of Minecraft Bedrock screens built in JsonUI, in the OreUI style. As the UI developer, I built a server explorer with a 'More' menu, a server page, a custom servers list, and a custom modal form. The modal form has reworked toggles, dropdowns, and inputs. The scrolling panels are cut cleanly at their edges.
