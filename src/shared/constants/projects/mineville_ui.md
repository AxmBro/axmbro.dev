Mineville UI is a custom JsonUI interface that [InPvP](https://inpvp.net/) commissioned for Mineville, a Minecraft Bedrock server. I built it from scratch - server forms, shops, trading, a custom inventory, and HUD elements such as a minimap and a scoreboard. The goals were easy navigation, one consistent brand look, and good performance with many players online. Most forms are animated, so [watch the showcase video](#showcase-video) to see them in motion.
