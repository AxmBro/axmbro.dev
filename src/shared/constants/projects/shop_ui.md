Shop UI is a vanilla-style shop screen for Minecraft Bedrock, built from scratch in JsonUI. It started as an experimental layout, and a private client later bought it for a custom server economy. As the UI developer, I built a scrollable grid of buttons, image tabs, hover text, discount labels, and a live search mode.
