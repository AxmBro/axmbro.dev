Zeqa UI is a custom JsonUI pack that [InPvP](https://inpvp.net/) commissioned for Zeqa, one of the largest Minecraft Bedrock PvP servers. As the UI developer, I built the server forms, grid menus, Battle Pass and level screens, and a few HUD changes. I worked from the client's documentation and tested and revised each screen with the team until it shipped. Most forms are animated, so [watch the showcase video](#showcase-video) to see them in motion.

Similar work for the same studio: [Mineville UI](/projects/mineville_ui).
